# Smallest Element in Array

This program finds the smallest element in an array.

## Features

* Takes array elements from the user
* Compares all elements
* Finds and displays the smallest element

## Technology Used

* C

## Concepts Used

* Arrays
* For loop
* Conditional statements
* Variables

## Sample Output

Enter the number of elements: 5
Enter 5 elements:
25 10 42 7 18
Smallest element: 7
